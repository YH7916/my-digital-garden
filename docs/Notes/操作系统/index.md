# 操作系统

操作系统的主线是：**让多个程序安全地使用CPU、内存和设备，并把硬件组织成进程、地址空间、文件等可用对象。** 本笔记按13章连续讲解，每章先提出具体问题，再解释术语、机制和例子，最后给记忆要点；图用于说明结构、事件与依赖。

## 学习路线

```mermaid
flowchart TB
    A["01导论与02结构：资源、权限、内核入口"] --> B["03进程与04线程：谁在运行，状态如何保存"]
    B --> C["05调度：CPU何时分给谁"]
    C --> D["06同步与07死锁：怎样共享与等待"]
    D --> E["08主存与09虚存：地址怎样转换，页面怎样留下"]
    E --> F["10文件接口与11实现：名字怎样找到数据块"]
    F --> G["12存储与13 I/O：设备怎样完成请求"]
```

先建立运行模型，再学习计算题。遇到状态题按“事件→状态”推演；调度题按下一个事件推进；地址和文件定位题先分解编号与偏移；性能题先列完整路径并统一单位。
